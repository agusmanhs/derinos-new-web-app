# Derinos Group - System Requirements

## 1. Public Website
- `/` - Home
- `/projects` - Project listing
- `/projects/[slug]` - Project detail
- `/properties` - Property listing
- `/properties/[id]` - Property detail
- `/construction` - Construction progress
- `/gallery` - Gallery
- `/about` - About company
- `/contact` - Contact

## 2. Admin Dashboard & Routes

## 3. Core Features
- **Project Management**: Create, update, archive projects. Manage locations, facilities, statuses (PLANNING, ACTIVE, CONSTRUCTION, COMPLETED, ARCHIVED).
- **Property Management**: Manage units within clusters/projects. Statuses: AVAILABLE, RESERVED, SOLD.
- **Construction Management**: Track phases (Planning to Handover) with progress, dates, and photo updates.
- **Lead Management**: Track leads (NEW to CONVERTED/LOST), assign to sales, view in Table/Kanban.
- **Booking & Sales**: Manage reservations, payment statuses.
- **Dashboard**: High-level metrics, charts (sales trends, performance), recent activities.
- **CMS**: Manage public website content dynamically without hardcoding.
- **SEO**: Semantic HTML, dynamic meta tags, Open Graph, sitemap, clean URLs.
